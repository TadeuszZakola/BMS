#Battery Management System  🔋⚡️

Welcome to the Battery Management System (BMS) project! 🚀 This open-source project combines cutting-edge hardware and software to deliver a robust, customizable solution for managing battery packs in applications like electric vehicles. With advanced monitoring, safety features, and seamless integration, this BMS ensures optimal battery performance and longevity. 🌱

🌟 Key Features



26 Individual Cell-Group Voltage Measurements ✅: Monitors voltage across 26 cell groups with high precision.



16 Temperature Sensors 🌡️: Provides comprehensive thermal monitoring to prevent overheating and ensure safe operation.



Cell Balancing 🔄: Actively balances cells to optimize capacity and extend battery lifespan.



Safety Relay 🔒: Isolates the battery pack during faults for enhanced safety.



Current Sensor ⚡: Enables real-time current monitoring and protection against overcurrent conditions.



CAN Bus 📊: Supports CAN communication for integration with external systems and data logging.



Advanced Safety Features 🛡️:





Over-voltage and under-voltage protection



Over-temperature shutdown



Current limiting via relay and BMS logic



Emergency cut-off for driver safety



Hardware & Software Integration 🛠️: Combines robust hardware (microcontroller, sensors, relays) with modular software for real-time monitoring and control.



User-Friendly Dashboard App 🖥️: Visualize battery metrics and configure settings through an intuitive interface.




CAN Integration: Supports CAN bus protocols for data transmission and external control.



Logging: Stores historical data for diagnostics and performance analysis.
